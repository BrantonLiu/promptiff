## 原有能力与补齐部分

- 已有：独立安装的 CLI / Skill、Codex 已记录会话采集、通用会话 JSON、本地画布链接、字面 / 本地模型 / 自有远程 embeddings 三种计算方式。
- 新增：`compare` 无需打开浏览器即可计算，返回与画布一致的双向匹配 JSON；Skill 增加用户启用后的每次文档交付约定。
- 采集修正：排除 Codex 内部续跑上下文，防止将其计为用户 prompt。
- 边界：未实现全局强制输出钩子、OpenClaw 专用日志适配器或跨设备云端报告。安装本身不意味着所有新任务自动执行。

## 实际执行

1. 按用户指定范围选择本项目一条名称切换计划任务，采集日志后，仅保留请求计划的原始输入和该轮实际交付正文；排除后续账号查询与执行讨论。
2. 将 Skill 安装到仓库外的临时目录，从安装目录的 runtime 启动全部命令，没有加载源仓库模块。
3. 对实际 2,104 字符的计划执行字面 `compare`，再使用已缓存的固定模型、`HF_HUB_OFFLINE=1` 执行真实本地语义 `compare`；两者成功生成报告。结果为 1 条输入句、80 条产出正文单元。
4. 启动本地语义画布，浏览器显示所选原始要求、实际计划正文、表格、标题与「本地语义」。浏览器完成模型计算，未以演示向量冒充结果。
5. 另做明确标注的模拟第二版：补充一条要求并追加对应正文，再执行比对。新要求字面匹配为 1；分别启动两份快照服务，核对链接不同且分别返回原版本和新版本，旧版不包含后续要求。
6. 实际 `npm pack` 后在临时目录解包，直接运行解包后的 CLI 比对成功。

- `npm test`：20 项通过，包括原有算法 / 安装 / 本地 API 防护，以及新增的版本截止、CLI / 画布一致性、报告权限与防覆盖、模型失败、内部消息过滤、远程所选文本和返回向量测试。

- 远程部分仅做受控 mock 和授权拒绝测试，未将真实会话发送到外部 API，未声称真实远程服务验收完成。
- 通用 JSON 路径适用于能读写文件并执行 CLI 的 Agent；本轮未在 OpenClaw 产品内完成安装或验证其自动调度行为。

短 prompt 对照长计划时，合理展开也可能得到低匹配。实际样本的低分不能等同于遗漏、违规或错误；需要 Agent 对照原文判断，尤其是多轮要求的冲突、数字、主体和否定变化。
