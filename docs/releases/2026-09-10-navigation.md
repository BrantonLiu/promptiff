# 2026-09-10 页面导航修复验收

## 问题与修复

- 生产首页实际点击“查看比对示例”后停留原页。控制台记录 vinext 的 Link RSC 预取和点击导航 TypeError。首页、返回首页、隐私说明、授权回调返回链接改用原生锚点导航。
