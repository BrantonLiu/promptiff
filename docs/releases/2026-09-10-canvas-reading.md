# 画布阅读体验修改

本轮在独立 worktree `wordiff-canvas-reading`、分支 `codex/canvas-reading` 完成，基于前轮 `codex/agent-canvas`。保留既有网站导航修复；本轮不部署生产。

## 变更

- 主界面以阅读为中心，默认收起句子出处，点选句子再展开；数据、阈值、计算与 Agent 接入集中到设置。
- 统一系统字体；桌面正文 15px、行高 28.5px；手机正文 14px。缩小标题层级，段落分组和浅色句子标记保持正常文档高度。
- Markdown 比对与预览共用安全解析器，支持基础标题、列表、引用、表格、代码和行内格式；标题与表头不计入正文得分。
- 用本项目两轮需求整理示例，包含两份完整方案与明确的示例出处说明。用固定 revision 的多语言 MiniLM 离线计算 47 条、384 维真实向量，浏览器按所选轮次重新计算对应关系。
- 独立 CLI 静态文件白名单与 Skill 安装包同步新增渲染器、示例及向量资源。

## 验证

本地开发预览：`http://localhost:4175/canvas/`，Codex 内置浏览器。桌面 1280 × 720、手机 390 × 844，手机检查后恢复默认视口。

实际走查：

- 句子语义、字面距离、逐句修订、原文预览切换；Markdown h1/h2、段落和列表正常渲染，原文预览无多余 `#` 标记。
- 选定示例句展开出处，显示 0.94 的真实语义相似度与对应原始需求；关闭出处正常。
- 初稿只有首轮可选；切换迭代版可选两轮；去掉第二轮会重新计算，恢复全选正常。
- 低匹配筛选将可见句数从 25 降至 15；设置中阈值从 0.65 调到 0.60 后同步更新。
- 设置三类面板切换正常；本地语义选项生成 `--engine local` 安装指令。
- 粘贴新的 Markdown 样本可进入画布，列表、表格、粗体、行内代码及围栏代码可见；嵌入的 script 保持源码，输出内没有 script 元素。自有文本标记为字面预览，不使用示例语义分数。
- 手机宽度无整页横向溢出，出处开关和设置可操作；设置弹窗宽度在视口内。
- 浏览器控制台未观察到 error / warn。

`npm test` 30 项通过，`npm run typecheck`、`npm run lint` 和完整站点 build 通过。构建仅有既有的大 chunk 提示。新增测试覆盖文档结构、纯文本边界、句子偏移、向量与示例一致性、按轮次重算，以及 CLI/Skill 新资源的可用性。

模型预计算以 `HF_HUB_OFFLINE=1` 执行，输入仅为整理后的示例。
