# 发布前基础按钮走查

每次发布前先 `npm run build`，再 `npm run start`，在终端显示的 Worker 预览地址里实际点击。开发服务器、HTTP 返回码、静态 HTML 和单元测试不能替代这些检查。

| 范围 | 操作与通过条件 |
| --- | --- |
| 首页入口 | 顶部与首屏的“查看比对示例”、底部“打开比对示例”以及四种模式的使用入口，点击后显示对应正文和正确 URL |
| 页面导航 | 品牌返回首页、隐私说明与返回链接、浏览器前进后退正确；功能目录能滚动到对应章节 |
| 模式与版本 | 四种模式及低、中、高版本能切换；选中状态、正文、指标与 URL 一致 |
| 审阅 | 隐藏删除开关确实隐藏/恢复删除文本；同步滚动开关切换后行为一致 |
| Diff | “只看变化”隐藏/恢复相同行；原文自对照时显示无变化 |
| 切词与语义 | 点击词/句可打开匹配详情；候选切换定位到原文；“下一处明显变化”移动到下一项；详情可关闭 |
| 弹窗 | 顶部算法按钮、指标说明、页脚说明均能打开；关闭按钮和 Escape 可关闭；原文自对照入口有效 |
| 复制与下载 | 点击复制后出现结果提示，剪贴板链接正确；下载按钮实际产生下载 |
| 手机宽度 | 首页入口可点、模式导航可用、原文/改写切换有效、弹窗关闭可点，没有遮挡主操作的元素 |
| 控制台 | 没有阻断导航、渲染或按钮行为的错误 |

登录与反馈的完整验证涉及外部授权和数据写入。改动相关流程时另测；未测时记录为未测，不能用配置接口成功冒充登录成功。

发布后，在生产站点再次点击“查看比对示例”、四种模式和返回首页，核对新资源已生效。每轮记录实际测试环境、操作结果、控制台错误与未测项。
