# 计算方法与限制

所有比较数据均由 `scripts/analyze.py` 预计算，浏览器读取随应用发布的数据，不在访问时调用大模型。原文与三个改写版本是算法输入，改写正文并非由 diff 算法产生。

## 四种比对方式

| 视图 | 比较单元 | 实际算法 | 颜色含义 |
| --- | --- | --- | --- |
| 审阅模式 | 全文字符 | Python `difflib.SequenceMatcher(autojunk=False)` | 黄色替换、灰蓝色纯增加、红色删除 |
| 类 Git Diff 比对模式 | 句子与长分句 | 先匹配比较单元，再展示块内字符差异 | 左侧删除、右侧增加或替换 |
| 切词比对模式 | jieba 词语 | 加权词语匹配、字符二元组与位置保留 | 蓝色字面较接近，黄色差距较大 |
| 按句语义比对模式 | 句子与长分句 | 句向量（embedding），归一化向量余弦最近邻 | 蓝色语义较接近，黄色差距较大 |

类 Git Diff 比对模式的替换块按位置配对只服务于版面，不代表语义对应。分句保留所有字符；长句超过 100 字先按逗号拆，再必要时定长拆分，拼接可无损恢复。模型计算前验证没有 tokenizer 截断。

## 切词比对模式

使用 jieba 0.42.1 精确模式，启用 HMM。每个改写句在所有原文句中寻找最佳匹配，匹配分数为：

```text
0.65 × IDF 加权词语 Dice + 0.35 × 字符二元组 Dice
```

Dice 是一种重合度分数。共有部分的量乘以 2，再除以两边各自总量之和。例如，不加权时，两句各有 4 个不同的词，其中 3 个相同，Dice = 2 × 3 ÷ (4 + 4) = 0.75。它衡量文字重合，不判断意思是否相同。

词语 Dice：两句共有的词（重复词取两句中较少的出现次数）按 IDF 加权，得分为 2×共有权重÷两句总权重；字符二元组 Dice：按相邻两个字符组成片段集合（含标点和空格，重复片段只计一次），得分为 2×共同片段数÷两句片段总数。IDF 使在原文句子中较少出现的词权重更高。该分数仅用于寻找最接近的原句，不是词语着色的分数本身。

找到原句后，通过最长匹配序列计算词语保留：原位相同为 1，移位复用为 0.65–0.85，新词为 `0.05 + 0.5 × 最佳字形相似度`。标点继承最近词的颜色。算法记录的分数不受显示羽化影响。

## 按句语义比对模式

- 模型：`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`。
- 固定 revision：`e8f8c211226b894fcb81acc59f3b34ba3efd5f42`。
- 模型自带 tokenizer、mean pooling、L2 归一化，384 维向量。
- 每个改写句与全部原文句计算余弦相似度，保留最佳匹配及前三候选。
- 首次重算从 Hugging Face 下载模型，之后在本地 CPU 推理，不发送文章到推理 API。

点击候选可以定位原文，帮助检查最近邻结果是否合理。语义色块是句子或长分句，不是逐词语义归因。

## 配色与指标

字面颜色区间为 0–1，语义颜色区间为 0.45–0.95；区间外颜色饱和。相邻色块用渐变羽化衔接；色块间不额外插入空格，原有换行和连续阅读保留。轻微圆角只影响绘制，悬浮与选中的细边框也不会改变计算结果。

字数按非空白字符计算，包含标点、数字。原样保留率分母为改写稿长度，段落重排会降低该比例。平均语义相似度按目标句字符数加权，是单向最近邻统计，不能充分揭示被删除的主张。逆向覆盖率采用 0.75 参考阈值。

相似度不能判定一句话是否确实来自作者、是否符合事实、是否由 AI 生成。否定词、数字、主体或立场变化可能被模型低估；尤其是高度改写，应结合原文与审阅结果判断。
