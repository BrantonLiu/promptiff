# 计算方法与限制

算法位于 public/canvas/core.mjs、document.mjs 与 cli/engine.mjs。

字面比对使用字符二元组 Dice 相似度逐句寻找最近的 prompt。Git比对与逐字比对在匹配文本间计算字符 LCS，分别并排展示原句与产出、在同一行显示增删改；双向覆盖分别从产出查 prompt、从 prompt 查产出，帮助发现扩展和遗漏。

语义比对使用真实句向量的余弦相似度。本地模型是 sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2，固定 revision e8f8c211226b894fcb81acc59f3b34ba3efd5f42。演示向量记录文本 SHA-256，用户文本未接入模型时明确显示字面预览。远程结果检查数量、维度、索引和非零性。

Markdown 标题与表头保留排版，不参与正文计分；导出保留原始文本。HTML 与代码仅显示源码，不执行脚本或加载外部资源。格式、长度限制和配置见 [Agent 接入说明](agent-canvas.md)。

平均值按输出字符加权，不是要求满足率、作者归属或 AI 生成概率。否定、数字与主体变化可能仍得高分。多轮 prompt 不自动裁定矛盾或撤销旧要求，需要人工判断。

画布模式顺序为语义比对、逐词比对、Git比对、逐字比对，原文预览为独立阅读入口。逐词比对先按字面最近句配对，再用浏览器内置 Intl.Segmenter（zh-CN、word）分词，按词序 LCS 标记原位保留（蓝）与新增、替换或移位（黄）。此视图不判断词义，不使用网站固定样本的 jieba 预计算分数。分词保留空白和标点，具体词边界可能随运行时词典版本变化。所有字面视图的句级相似度与需求对应指标仍采用字符二元组 Dice；最近邻配对不代表 Git 文件行对齐、完整编辑历史或因果来源。
