# Kimi CLI · kimi-code/k3 原始建议

此页保留模型原始建议，供比较使用，并非全部采用。算法中“先去空白”的说法有误，最终稿已按代码纠正。

整体去掉了口号式表达（'让每一处改写，有迹可循'、'让改写有迹可循'）、反问式标题（'意思呢？'、'意思走远了吗？'、'还留着原来的痕迹？'）和'意思走远''原来的痕迹'等修辞，替换为直接说明能做什么的陈述句。四种模式全站统一为'审阅模式 / 类 Git Diff 比对模式 / 切词比对模式 / 按句语义比对模式'，包括首页卡片、工作区标签、反馈问卷选项、SEO 描述、README 与方法文档。'怎么算/怎么看'改为'算法原理/比对方式'。Dice 在首页步骤、实验说明弹窗和方法文档三处给出统一解释：共有词按 IDF 加权（重复词取较少次数），2×共有权重÷两句总权重；二字片段先去空白按相邻两字计数，2×共同片段÷总片段；65/35 加权仅用于检索原句，不是着色分数；IDF 让原文中少见的词权重更高。用户建议的'导入原始需求和 AI 输出'未采用——当前是固定样本演示，不能承诺导入功能，首页导语改为明确说明'用同一篇口述和三种 AI 改写演示四种比对方式'。相似度免责声明在首页结尾和工作区页脚补充'不能断定原意未变'。改写正文、原文、署名、事实补充、指标说明等算法输入与事实注释一律未动；隐私页信息完整保留，未增加任何承诺；路由、id、参数、数据字段未动。已直白准确的短标签（接近原文/差距较大/只看变化/同步滚动/隐藏删除/改写程度等）保留。
